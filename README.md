## 🛠 Troubleshooting common issues

If you encounter problems, check these solutions before you ask for help.

*   **The program does not open:** Check if you have the latest Windows updates. Restart your computer and try again.
*   **The file will not open:** Make sure the archive is not password protected. Currently, the program does not support encrypted archives.
*   **Slow performance:** Large archives take more memory. Avoid opening multiple large archives at the exact same moment.

## 🛡 Security and Privacy

archivefree respects your data. The application does not send your files to any server. All processing happens on your local machine. Because this is free software, you can trust that it operates without hidden agendas. It uses standard library tools to read files, which keeps the process secure.
